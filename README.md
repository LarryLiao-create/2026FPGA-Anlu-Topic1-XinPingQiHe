# 芯屏气和：基于 EG4S20 的 HDMI 多媒体播放系统

2026 全国大学生嵌入式芯片与系统设计竞赛 FPGA 创新设计赛道 · 安路科技企业选题一

本作品基于安路 EG4S20 FPGA，实现了一款面向智慧医疗场景的“医屏通”离线多媒体信息发布终端。系统不使用处理器软核，TF 卡 BMP 图片解析、SDRAM 帧缓存、HDMI 视频输出和 I2S 音频播放全部由硬件逻辑完成，宣传图片写入 TF 卡即可离线更新。

## 主要功能

- **图片轮播**：读取 TF 卡中最多 4 张 24 bit BMP，支持按键手动切换和自动轮播。
- **多图层 OSD 叠加**：底部滚动字幕、右上角时间戳、左上角亮度数值和右下角安路 Logo。
- **淡入淡出转场**：切图时逐行读取新旧两帧做硬件 Alpha 混合，64 帧约 1.075 s。
- **自适应等比缩放**：任意尺寸图片（最大 2048×2048）等比缩放到 640×480，自动补黑边。
- **亮度调节**：按键 8 档调节亮度，只作用于底图，不影响 OSD。
- **音频与波形可视化**：DDS 合成音乐经 HDMI 输出，屏幕实时绘制音频时域波形。
- **医院叫号面板**：拨码开关叫号，显示当前号码、历史队列和等待人数，并伴有提示音。
- **多级防卡死**：看门狗配合局部复位与整链复位，单张图片异常时仍可继续轮播。

## 快速上手

1. **准备 TF 卡**：把 24 bit BMP 图片拷入 TF 卡（`doc/TF卡图片/` 中有示例；其他格式可用 `doc/convert/convert_images_to_bmp.py` 转换）。
2. **直接上板**：用 TD 下载 `src/td_project/HDMI1.4b_Transmitter_v1.0_Runs/best_result/HDMI1.4b_Transmitter_v1.0.bit` 到 HX4S20 开发板。
3. **重新编译（可选）**：用 TD V6.2 打开 `src/td_project/HDMI1.4b_Transmitter_v1.0.al`，依次综合、布局布线、生成比特流。
4. 插入 TF 卡，HDMI 连接显示器，上电即开始轮播。

## 操作说明

| 输入 | 功能 |
| --- | --- |
| key1 | 下一张图片 |
| key2 | 开 / 关自动轮播 |
| key3 | 亮度调节（8 档循环） |
| rst_n | 复位 |
| SW1 | 叫下一号（带提示音） |
| SW2 | 显示音频波形 |
| SW3 | 打开叫号记录面板 |
| SW4 | 等待人数 +1 |
